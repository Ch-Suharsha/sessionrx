# sessionrx

## Agent skills

Use the installed skills from `mattpocock/skills`. User-invoked skills require an explicit user request; model-invoked skills may be used when the task fits.

### Issue tracker

Track issues, specs, and implementation tickets in this repository's GitHub Issues. Before reading or publishing tickets, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five canonical triage label names. Before triaging or applying labels, read `docs/agents/triage-labels.md`.

### Domain docs

Use a single context: root `GLOSSARY.md` and `docs/adr/`. Before exploring the project or recording domain terms and decisions, read `docs/agents/domain.md`.
